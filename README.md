# Soulslike Character Creation UI

A minimal, atmospheric character creation screen inspired by Souls-like games.

No gameplay.  
No backend.  
Just ritual, restraint, and mood.

This project explores how **UI alone** can convey commitment, weight, and finality.

---

## ✨ Features

- Class selection with locked fate
- Lore-based class descriptions
- Starting equipment reveal
- Starting gift selection (locked)
- Derived stats (HP, Stamina, Level)
- Fade-to-black **“Begin Journey”** ending
- Silent persistence using `localStorage`

---

## 🎮 Experience Philosophy

This is not a game.

It is a **moment** — the beginning of one.

Choices are:
- Previewed before commitment
- Locked once chosen
- Remembered across sessions

There are no confirmations, alerts, or resets by default.  
The UI is meant to feel deliberate, quiet, and final.

## 💾 Persistence

Your final character build is automatically saved using `localStorage`.

Closing the tab does not reset your fate.

## 🤍 Why This Exists

Built purely for fun, curiosity, and to explore:
- Mood-driven UI design
- Minimalist interaction
- When **not** to add more features

Sometimes the hardest part of design is knowing when to stop.
